Introduction
This assignment requires you to implement and evaluate one machine learning
model of your choice. You may use a programming language of your choice for this
assignment.
You are strongly encouraged to consider the use of scikit-learn, OpenCV,
TensorFlow, CudaNN or MLPack for these tasks. Additionally, you can make use of
example programs supplied to you during this module of study. If you intend to use
libraries or programs other than these, please consult your lecturer first.
Task 1 (70 marks total)
You must choose a learning algorithm and also choose a dataset/problem that can
be used to demonstrate the algorithm working.
Once you have chosen a learning algorithm from the list above and your dataset,
document the process of running and testing your learning algorithm.
Required Documentation Task 1:
● Include information on how to run your program and any software
dependencies.
● The details of the dataset including the features that you used.
● A description of the algorithm implementation and parameters used
● A description of how you trained the algorithm.
● The results you obtained.

N.B. The performance of your algorithm should be optimised as best as you can -
and you must document how you approached this - this is where extra marks will be
awarded if you have used an appropriate approach. However, if your algorithm
implementation is not correct, you will get less marks.

Task 2 (30 marks total)
Discuss your algorithms ability to solve various problems and also discuss the
limitations that your chosen method can have.
Finally, briefly discuss areas where these methods are used today.
